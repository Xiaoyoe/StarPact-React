# 局域网媒体分享功能

## 功能概述

局域网媒体分享功能允许用户在本地网络中分享电脑上的图片和视频，其他设备（如手机、平板）可以通过浏览器访问这些媒体内容，无需上传到云端，实现零流量消耗的媒体分享。

## 核心功能实现

### 1. 服务器启动流程

```rust
// 1. 检查服务器是否已运行
if SERVER_RUNNING.load(Ordering::SeqCst) {
    return Err("Server is already running".to_string());
}

// 2. 获取本地IP地址
let local_ip = local_ip_address::local_ip()?;

// 3. 绑定到所有网络接口
let addr: SocketAddr = format!("0.0.0.0:{}", port).parse()?;

// 4. 启动异步HTTP服务器
tokio::spawn(async move {
    axum::serve(listener, app_router)
        .with_graceful_shutdown(shutdown_signal)
        .await
});
```

### 2. 视频流式传输

支持两种传输模式：

#### 流式传输（推荐）
```rust
// 边读边发，内存占用恒定约1MB
let stream = ReaderStream::new(file);
let body = Body::from_stream(stream);
```

#### 缓冲传输
```rust
// 先读取整个文件到内存，再发送
let bytes = tokio::fs::read(path).await?;
let body = Body::from(bytes);
```

### 3. Range 请求支持（视频拖动）

```rust
// 解析 Range 请求头
// 例如: Range: bytes=0-1023
if let Some(range_header) = headers.get(header::RANGE) {
    let range = parse_range(range_str, file_size)?;
    // 只读取请求的字节范围
    file.seek(std::io::SeekFrom::Start(range.start)).await?;
    // 返回 206 Partial Content
}
```

## 流量消耗分析

### 技术原理

```
┌─────────────────────────────────────────────────────────────┐
│                    网络拓扑分析                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  场景1: WiFi路由器局域网                                     │
│  ┌─────────┐         ┌─────────┐         ┌─────────┐       │
│  │  电脑   │ ────────│ 路由器  │─────────│  手机   │       │
│  │(服务器) │  本地   │(交换机) │  本地   │(客户端) │       │
│  └─────────┘  传输   └─────────┘  传输   └─────────┘       │
│                    ↓                                        │
│              不经过运营商网络                                │
│              不消耗流量 ✓                                   │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  场景2: 手机热点局域网                                       │
│  ┌─────────┐         ┌─────────┐         ┌─────────┐       │
│  │  电脑   │ ────────│华为手机 │─────────│小米手机 │       │
│  │(服务器) │  本地   │ (热点)  │  本地   │(客户端) │       │
│  └─────────┘  路由   └─────────┘  路由   └─────────┘       │
│                    ↓                                        │
│              数据在手机内部路由                              │
│              不经过移动基站 ✓                               │
│              不消耗运营商流量 ✓                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 为什么手机显示"流量使用"？

| 显示项 | 实际情况 |
|--------|----------|
| 手机系统流量统计 | 统计所有经过热点网络的数据（包含本地传输） |
| 运营商流量计费 | 只计算经过移动基站的数据 |

**结论：手机显示的"流量使用"只是统计数字，不等于实际扣费！**

### 验证方法

1. 记录当前运营商流量余额
2. 用电脑传输 1GB 视频给手机
3. 再次查看流量余额
4. 如果余额没有减少 1GB，说明本地传输不计费

### 代码层面的验证

```rust
// 服务器绑定地址
let addr: SocketAddr = format!("0.0.0.0:{}", port).parse()?;
// 0.0.0.0 表示监听所有网络接口，包括本地回环和局域网接口

// 获取的是局域网IP，不是公网IP
let local_ip = local_ip_address::local_ip()?;
// 例如: 192.168.43.x (热点) 或 192.168.1.x (WiFi)
```

## 传输模式配置

在 **设置 → 通用** 中可以选择传输模式：

| 模式 | 内存占用 | 适用场景 |
|------|----------|----------|
| 流式传输（推荐） | 恒定约 1MB | 大文件、长时间视频 |
| 缓冲传输 | 等于文件大小 | 兼容性要求高的场景 |

### 配置存储

```rust
// config.rs
pub struct UiConfig {
    #[serde(default = "default_lan_transfer_mode")]
    pub lan_transfer_mode: String, // "streaming" 或 "buffered"
}
```

## 使用指南

### 1. 启动服务器

1. 打开应用侧边栏
2. 找到"局域网分享"区域
3. 点击"启动服务器"按钮
4. 记下显示的地址（如 `http://192.168.1.100:8080`）

### 2. 连接设备

1. 确保手机和电脑在同一个网络下
   - 同一个 WiFi 路由器
   - 或者同一个手机热点
2. 在手机浏览器中输入显示的地址
3. 即可访问媒体中心

### 3. 浏览媒体

- 点击"图片库"浏览图片
- 点击"视频库"观看视频
- 支持"多视频播放"同时播放多个视频

## 性能优化

### 1. 视频传输优化

- **Range 请求支持**：支持视频进度拖动，只加载需要的部分
- **流式传输**：大文件不会占用过多内存
- **分块读取**：每次只读取请求的数据块

### 2. 前端优化

- **分页加载**：图片和视频列表分页显示
- **懒加载缩略图**：视频缩略图按需生成
- **虚拟滚动**：大列表流畅滚动

### 3. 内存优化对比

| 场景 | 缓冲传输 | 流式传输 |
|------|----------|----------|
| 2GB 视频 | 占用 2GB 内存 | 占用约 1MB 内存 |
| 4小时视频 | 启动慢，需等待加载 | 即点即播 |
| 多用户同时访问 | 内存爆炸 | 稳定运行 |

## 常见问题

### Q1: 手机显示消耗流量，会扣费吗？

**不会。** 手机系统统计的是所有经过热点网络的数据，但运营商只对经过移动基站的数据计费。局域网传输是本地路由，不经过基站。

### Q2: 为什么有时候连接不上？

检查以下几点：
1. 确认电脑和手机在同一个网络
2. 检查电脑防火墙是否允许 8080 端口
3. 确认服务器已启动

### Q3: 视频播放卡顿怎么办？

1. 确保使用"流式传输"模式
2. 检查网络信号强度
3. 尝试降低视频分辨率

### Q4: 支持哪些文件格式？

**图片**: JPG, JPEG, PNG, GIF, WebP, BMP
**视频**: MP4, WebM, MKV, AVI, MOV, M4V

- Rust 异步编程实现高并发

- 流式传输优化内存使用
